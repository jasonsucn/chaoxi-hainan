# 潮汐书 · 海南 / 声音地图 SOUND MAP

**版本** R0 · 2026-10-23  
**归属** word-sound  
**读取顺序** `docs/ART-DIRECTION.md` → `docs/PLAN-5ACTS.md` → `docs/ACT-INTERFACE.md` → 本册  
**范围** 00 满潮（沿用 M0，不改 `js/audio.js`）+ 01–05 五幕 + 交叉淡化 + 移动端解锁 + 静音记忆 + 程序化/采样边界  
**边界** 本册只描述声音系统；不改 `js/audio.js`、`js/app.js`、`index.html`。可选原型在 `labs/sound/`，不进单文件构建。

> 画面只有一条水线。声音也只有一条：  
> 不做通用淡入淡出，做「进水 / 出水」。

---

## 0. 五条原则

1. **水线驱动，不靠时间。** 全局 `tide`（0..1）和 `lineY` 决定「水下 / 空气」两条总线的增益、滤波和宽度；幕与幕的交叉必须由水线位置触发，不由 `setTimeout` 触发。
2. **滤波先动，增益后动。** 进来的层先在水下（低通）出现，再把高通打开；出去的层先把高频关掉，再降到 0。这样听起来是「浮出 / 沉下」，不是「淡入 / 淡出」。
3. **没有音频文件。** 守住 M0 / README 的承诺：全部程序化合成，单文件 0 音频字节。可选采样只做研究，不进交付（见 §7）。
4. **默认关，手势开，记住选择。** 不自动播放；移动端必须在用户手势里创建 / 恢复 `AudioContext`；静音状态持久化，但每次会话仍要一次手势才能真的响。
5. **每幕 2–4 层，同一时间只有当前幕可闻。** 相邻幕可以预建节点，但增益为 0；隐藏的幕暂停，页面不可见时挂起。

## 1. 信号图

```
                       ┌─ [wet bus]  lowpass 300–1200Hz  ─┐
[act layers] → [act gain] ─┤                                 ├→ [master] → [limiter] → destination
                       └─ [dry bus]  highpass 600–2000Hz ─┘
                                      ↑
                          tide / lineY → waterline mapper
[interaction one-shots] → [fx bus] ────┘
```

- `wet` / `dry` 是**同一条混音**的两个滤波分支，不是两套独立的床。`tide=0`（满潮）时 wet 开、dry 关；`tide=1`（见底）时反过来。等功率交叉，留 0.02 的底，避免死寂。
- 每层仍有自己的滤波 / 包络（材料性）；总线的滤波只负责「在水里还是在空气里」。
- 00 满潮沿用 M0 的 `js/audio.js`（它已经有一对水下 / 空气床和 48 / 72.5Hz 正弦）。新的 `Sound` 从 01 开始接管；00→01 用 1.4s 交叉，M0 的 `Ambience` 只降不升。
- 不碰 `js/audio.js`。如果 Lead 决定统一，R2 再把 00 的节点搬进新引擎；R0/R1 保持共存。

### 1.1 建议 API（给 Lead）

```js
Sound.init({ getTide: () => tide, getLineY: () => lineY });
Sound.unlock();                 // 必须在 pointerdown / keydown / touchend 里调用
Sound.setMuted(bool);           // 持久化
Sound.setAct('03', 0.4);        // 当前幕 + 局部 p；内部做 0.35–1.2s 交叉
Sound.update(state);            // 每帧或 10–20Hz：{tide, lineY, pointer, velocity, reduced}
Sound.event('pick', {act:'02'});// 一次性事件
Sound.pause(); Sound.resume();  // visibilitychange / 幕隐藏
```

`state` 直接复用 `docs/ACT-INTERFACE.md` 的 `state`，外加 `velocity`（拉海速度，用于交叉时长和颗粒密度）。

## 2. 五幕声音弧

一句话：**水 → 石 → 沙 → 珊瑚 → 纸 → 水。** 两个「干」幕（01、04）最安静；02 细节最多；03 最沉浸；05 回到 00 的床，合上书。

| 幕 | 密度 | 主材质 | 动态 | 关键事件 | 静默 |
|---|---|---|---|---|---|
| 00 满潮 | 低 | 水下棕噪 / 空气 / 48·72.5Hz | 平 | 拉海、回潮 | 无 |
| 01 玄武 | 最低 | 石头 / 风 / 极低共鸣 / 热 | 窄 | 按住升温、松手降温、干拍 | 干拍 80ms |
| 02 潮间带 | 最高 | 浪 / 沙 / 纸 / 远山 | 宽 | 拖水线、拾字、四件证物 | 每 20–40s 留 0.8s 空 |
| 03 珊瑚 | 最细 | 水下 / 涌 / 鼓虾 / 光 / 产卵 | 中 | 停光 2s、产卵 | 产卵前 200ms |
| 04 航线 | 干 | 纸 / 铅笔 / 星图 / 针 | 中 | 划笔、过针位、到岸 | 划完 0.4s |
| 05 归潮 | 回到水 | 水 / 月 / 纸 / 石 | 宽 | 收下、盖章、再等一次潮 | 盖章后 1.2s |

**弧线读法**

- 00 是「在水里」；01 是「水退到石头」，所以声音要**变干、变窄、变少**，只剩石头和极低频。
- 02 是潮间带，水最浅、细节最多：浪、沙、纸、远山同时存在；这是全篇唯一允许「密」的幕。
- 03 是夜里潜下去：空气总线关掉，水下总线打开；最安静，但信息量在细碎的鼓虾声和产卵颗粒里。
- 04 是纸上的海：干、近、低；只有铅笔和星图的低频。
- 05 是水回来：00 的床回来，01 的石头 tick 作为最后一次回响；盖章之后留 1.2s 真静默，再回到 00。

## 3. 每幕层表

电平是相对 master 的近似值；最终以 limiter 前的实测为准。

### 00 满潮 / HIGH WATER（M0，锁定）

| ID | 层 | 类型 | 合成 | 滤波 / 频率 | 调制 | 电平 |
|---|---|---|---|---|---|---|
| `00.uw` | 水下 | water | 棕噪 4s loop | LP 420Hz Q0.8 | LFO 0.07Hz，±150Hz | 0.62 × (1 − 0.82 × pull) |
| `00.air` | 空气 | wind | 白噪 4s loop | HP 1050Hz → LP 4200Hz | — | 0.08 + 0.30 × pull |
| `00.sub` | 两个正弦 | star | 48Hz / 72.5Hz | — | — | 0.05 / 0.018 |

不改 `js/audio.js`。新引擎在 00 区间把 master 让给 `Ambience`；到 01 前 1.4s 开始接管。

### 01 玄武 / BASALT（4 层）

| ID | 层 | 类型 | 合成 | 滤波 / 频率 | 包络 / 调制 | 电平 |
|---|---|---|---|---|---|---|
| `01.stone` | 石头 tick | material | 白噪 → BP 260Hz Q1.6 + BP 520Hz Q2.0 | 260 / 520Hz | 每 0.5–2.2s 一个 40–140ms 颗粒（attack 3ms，decay 80ms） | −26 dB |
| `01.sub` | 极低共鸣 | star | sine 38Hz + 57Hz（五度） | — | 0.02Hz 慢拍；heat > 0.6 时加 76Hz | −30 dB |
| `01.wind` | 风 | wind | 白噪 → BP 700Hz Q0.7 → LP 1800Hz | 700 / 1800Hz | LFO 0.05Hz，depth 0.02；`tide > 0.5` 才开 | −36 dB |
| `01.heat` | 热 | material | 棕噪 → LP 600→2400Hz（跟随 heat） | 600–2400Hz | `gain = heat^1.4 × 0.22`；松手 3.5s 衰 | −24 dB |

- **warmStart**：`heat 0→1` 用 2–4s（跟随按压），LP 从 600 开到 2400，`01.sub` 的 76Hz 在 heat > 0.6 时进入。
- **warmEnd**：heat 用 3.5s 回落（比来慢），LP 收回到 600。
- **dryBeat**：01 退场时，master 下陷 80ms（5ms ramp），同时给一个 `01.stone` tick；这是「干」的声音签名。
- 交叉：00→01 时 48Hz 微微落到 38Hz，水下床让位给石头；01→02 时石头颗粒从 2/s 降到 0，浪进来。

### 02 潮间带 / INTERTIDAL（4 层）

| ID | 层 | 类型 | 合成 | 滤波 / 频率 | 包络 / 调制 | 电平 |
|---|---|---|---|---|---|---|
| `02.surf` | 浪 / 水膜 | water | 棕噪 → LP 900Hz Q0.7；白噪 → HP 2.4kHz（薄膜） | 900 / 2400Hz | 振幅 LFO 0.08Hz，depth 0.35；宽度 0.8 | −22 dB |
| `02.sand` | 沙 / 贝壳 | material | 白噪 → BP 1.8kHz Q0.9 颗粒；2–4ms 脉冲 → BP 4.2kHz（贝壳） | 1800 / 4200Hz | 6–14 粒/s；贝壳 0.4–1.6s 一次；随机声像 | −30 / −34 dB |
| `02.paper` | 字 / 纸 | paper | 白噪 20ms → BP 2.8kHz Q1.2 + 五声音高 | 2800Hz + 293.66 / 329.63 / 392 / 440 / 523.25Hz | 2ms attack / 90–220ms decay | −20 dB |
| `02.far` | 远山 | creature | 三角波 F0 380→520→300Hz，3 个共振峰（800 / 1250 / 2600Hz）+ 2 个 delay tap | 800–2600Hz | 50–90s 一次；1.4s；声像 ±0.8 | −38 dB |

- **pick**：`02.paper` + 一个音高。五个字各一个音高，`拾` = D4（293.66Hz），尾巴最长 220ms。
- **evidence**：拾起黎锦线 / 盐晶 / 落叶 / 远山猿啼时，`02.far` 短暂开 2dB，纸 tick 更低、更短；不弹窗、不打断拖拽。
- **release**：松手、水擦掉半成字时，`02.surf` 做一次 300ms 向下的滤波扫（900→500Hz），不是淡出。
- 交叉：01→02 浪从 dry bus 进来（水线刚过沙），石头 sub 留在 −6dB 做地板；02→03 空气总线 1.2s 关闭，沙粒被 LP 吞掉，`03.under` 接管。
- `02.far` 在 03 保持 −38dB，到 04 才退。这是「声音里保留一层远山」。

### 03 珊瑚 / CORAL（4 层）

| ID | 层 | 类型 | 合成 | 滤波 / 频率 | 包络 / 调制 | 电平 |
|---|---|---|---|---|---|---|
| `03.under` | 水下 | water | 棕噪 → LP 280Hz Q0.7 | 280Hz | 涌 LFO 0.04Hz，depth 0.25 | −24 dB |
| `03.surge` | 涌 | water | 白噪 → BP 180Hz Q0.8 | 180Hz | LFO 0.06Hz；宽度 0.9 | −30 dB |
| `03.reef` | 鼓虾 / 珊瑚 | creature | 2–6ms 脉冲 → BP 3.2kHz Q2.5，10–24 次/s；触手 tick 为 40ms 的 BP 1.2kHz | 3200 / 1200Hz | 随机间隔；随机声像 | −32 / −36 dB |
| `03.light` | 光 | star | sine 1600Hz + 2400Hz | LP 4kHz | tremolo 0.3Hz；增益跟 `light` | −36 dB |

- **light**：pointer 移动时 `light` 上升；停住 2s，触发 `spawn`。移开光，`light` 下降，`03.reef` 的触手 tick 停止。
- **spawn（产卵）**：所有床 −6dB / 120ms → 200ms 近静默 → 颗粒云：60–90 粒/s，每粒 5–18ms，BP 1.2–4.5kHz，中心 700→1800Hz / 4s，宽声像，峰值 −18dB；下面垫一个 96Hz 的 bloom（attack 1.2s，decay 5s，−28dB）。6–8s 衰。
- 交叉：02→03 空气总线关 1.2s；03→04 水退（空气总线 1.8s 开），产卵尾巴自然衰，纸的翻页声进来。
- 注意：真实产卵不是光触发；这是交互隐喻。声音是「细碎的产卵声」，不是真实录音。

### 04 航线 / ROUTE（4 层）

| ID | 层 | 类型 | 合成 | 滤波 / 频率 | 包络 / 调制 | 电平 |
|---|---|---|---|---|---|---|
| `04.paper` | 纸 | paper | 白噪 → HP 1.2kHz → LP 6kHz；翻页 = 260ms BP 扫 700→3.5kHz | 1200–6000Hz | 慢 LFO 0.04Hz；进幕一次翻页 | −30 / −28 dB |
| `04.pencil` | 铅笔 | material | 白噪 → BP 2.4kHz Q0.8 | 2400Hz | 增益跟 `traceSpeed` 0.01–0.12；停笔 0 | −26 dB |
| `04.star` | 星图 | star | sine 55 / 82.5 / 110Hz + 2.2–4.4kHz 星点 ping | 55–110Hz / 2.2–4.4kHz | 慢拍；星点 3–7s 一次 | −34 / −40 dB |
| `04.needle` | 针 | material | 1ms 脉冲 → BP 5.5kHz Q3；到岸 = 180Hz + 噪 → 80ms | 5500Hz / 180Hz | 过 24 针位各一次；到岸一次 | −30 / −26 dB |

- **traceStart**：`04.pencil` 从 0 到 `traceSpeed` 映射，40ms ramp；线过水线时，`04.star` 开 1.5dB（星金出现的听觉对应）。
- **traceEnd**：笔停，`04.pencil` 80ms 收；一个干的 tick。
- **waypoint**：每过一个针位，`04.needle` 一声；不要做成节拍器，间隔跟着手速。
- **nameReveal**：到岸，180Hz 木刻 tick + 星点 ping；旧名出现后留 0.4s 空。
- 交叉：03→04 水退、纸进；04→05 星图沉下去，翻页，水回来。

### 05 归潮 / RETURN（4 层）

| ID | 层 | 类型 | 合成 | 滤波 / 频率 | 包络 / 调制 | 电平 |
|---|---|---|---|---|---|---|
| `05.return` | 水回来 | water | 棕噪 → LP 300→420Hz / 4s | 300–420Hz | 4s 开；回到 00 的床 | −22 dB |
| `05.moon` | 月 | star | sine 1500Hz + 2250Hz | LP 3kHz | tremolo 0.12Hz | −38 dB |
| `05.paper` | 卡 / 盖章 | paper | 卡面滑入 = 220ms 白噪 1–4kHz；盖章 = 72Hz sine 160ms + 30ms 噪 | 1000–4000Hz / 72Hz | 一次性 | −26 / −20 dB |
| `05.stone` | 石头回响 | material | 复用 `01.stone` 的一个 tick | 260Hz | 结束前一次 | −34 dB |

- **card**：潮汐笺出现，纸滑入 220ms；不要「叮」。
- **save（收下）**：盖章 = 72Hz 的 thud + 30ms 纸噪；随后 1.2s 真静默。
- **replay（再等一次潮）**：2.5s 反向涌（空气总线关、水退），回到 00 的床；不要用倒放音频，用滤波和包络做「反向」的感觉。
- 交叉：04→05 纸退水进 2.4s；结束回到 00 的 48 / 72.5Hz，master 4s 降到 0（如果用户不重播）。

## 4. 交叉淡化规则

### 4.1 幕区间

以 Lead 的 `js/core/chapters.js` 为准。下面是建议默认值（可按实际 `act` 比例覆盖）：

| 幕 | `tide` 区间 |
|---|---|
| 00 | 0.00 – 0.07 |
| 01 | 0.07 – 0.24 |
| 02 | 0.24 – 0.47 |
| 03 | 0.47 – 0.67 |
| 04 | 0.67 – 0.86 |
| 05 | 0.86 – 1.00 |

边界 ±0.015 是交叉带；在带内按 `lineY` 的实际位置插值，不按时间。

### 4.2 曲线

- **等功率**：`gIn = sin(x·π/2)`，`gOut = cos(x·π/2)`；不要线性叠出中间凸起。
- **时长**：静止 0.9s；快速拖动（`|velocity| > 1.5/s`）0.35s；最小 0.25s，防咔哒。用 `setTargetAtTime`（timeConstant = 时长/4）+ 末尾 10ms 线性收尾。
- **滤波先行**：进来的层 LP 从目标值的 30% 开始，在交叉期内开到 100%；出去的层先把 LP 收到 30%，再降增益。听感是「从水里浮出来 / 沉下去」，不是「音量推子」。
- **层启停**：所有源以 0 增益启动，50ms ramp 入；停时 80ms ramp 出，再 `stop()`。禁止裸 `start()` / `stop()`。
- **干拍**：01 退场、05 盖章前，master 下陷到 −60dB 80ms，5ms ramp；这是全篇唯一的「硬切」，要有，但不能爆。
- **闪避**：一次性事件（拾字、盖章、到岸）让床降 2–3dB、250ms，手动包络；不要用 sidechain compressor。
- **声像**：120Hz 以下保持单声道；`StereoPannerNode` 只给中高频；不要 Haas 延迟 > 20ms。
- **空间**：不用 Convolver（CPU 和单文件都不划算）；2–3 个 delay tap（120 / 260 / 480ms），反馈 ≤ 0.18，delay 后加 LP。水下感靠 LP，不靠混响。
- **总线**：master −6dB 余量 → limiter（threshold −10dB，knee 6，ratio 12，attack 3ms，release 250ms）→ destination。峰值目标 ≤ −6dBFS，不做响度战争。

### 4.3 暂停 / 恢复

- `visibilitychange` 隐藏：master 120ms 降到 0，300ms 后 `ctx.suspend()`。
- 回到可见：不自动恢复；下一次手势再 `resume()`。如果之前是开的，恢复后 400ms 回到原电平。
- 幕隐藏（非当前幕）：该幕的层 400ms 降 0，2s 后停止；预建的下一幕保持 0 增益。

## 5. 移动端解锁

1. **懒创建**：`AudioContext` 只在用户手势里创建（声音按钮、第一次拖水线、第一次按键都算）。不要在 `DOMContentLoaded` 里 new。
2. **手势里 resume**：`ctx.resume()` 必须在同一个手势调用栈里；如果 100ms 后仍是 `suspended`，UI 显示「待解锁」，下一次手势重试。
3. **iOS**：手势里播一个 1 sample / 0.02s 的静音 buffer（或启动一个 0 增益的短源），这是老 iOS 的解锁习惯；监听 `ctx.state === 'interrupted'`（来电 / Siri），在 `visibilitychange` 或下一次手势里 `resume()`，不要无限重试。
4. **Android**：延迟可能 100ms+；一次性事件排在 `ctx.currentTime + 0.03`，不要排 0。
5. **一个 context**：开关声音不重建 context；如果被系统关闭，下一次手势重建。
6. **UI 三态**：`OFF` / `ON` / `待解锁`。不要在 context 还是 suspended 时显示 `ON`。
7. **不自动播放**：即使用户上次开着，也要等第一次手势；在等的时候按钮可以显示 `ON · 待解锁`，但不要发声。
8. **测试矩阵**：iOS Safari、iOS Chrome、Android Chrome、桌面 Chrome / Safari / Firefox；耳机与外放各一次；后台切回一次。

## 6. 静音记忆

| key | 值 | 说明 |
|---|---|---|
| `tidebook.sound.muted` | `"1"` / `"0"` | 默认 `"1"`；只在用户点过声音按钮后写入 |
| `tidebook.sound.seen` | `"1"` | 可选：是否看过声音提示 |
| `tidebook.words` | JSON | 拾到的五个字；和声音无关，但同属「本机记忆」 |
| `tidebook.card` | JSON | 最后一次潮汐笺数据 |

- **默认静音**。第一次进入不发声，按钮 `OFF`；用户点开才建 context、写 `"0"`。
- **下次进入**：读 `"0"` → 按钮显示 `ON`，但仍是 suspended；第一次手势后 `resume()` 并真的响。读 `"1"` → `OFF`，不建 context。
- **静音**：300ms 降到 0，400ms 后 suspend；写 `"1"`。**取消静音**：resume，400ms 回到 0.32；写 `"0"`。
- **页面隐藏**：挂起；回来不自动恢复，下一次手势恢复（如果上次是开的）。
- **降级**：`prefers-reduced-motion` 不阻止声音，但**不自动开**；用户开时 LFO 深度减半、颗粒密度减半、产卵颗粒云时长减半。
- **重置**：开发期用 `?sound=reset` 清掉 `tidebook.sound.*`；不进正式 UI。

## 7. 程序化 vs 采样

| 层 | 来源 | 说明 |
|---|---|---|
| 00 水下 / 空气 / 正弦 | 程序化 | 现有 `js/audio.js`，不改 |
| 01 石头 / 风 / 共鸣 / 热 | 程序化 | 噪 + 滤波 + 正弦；热是滤波开合 |

**建议：100% 程序化。** 原因：

- 守住 README 的「运行时不加载任何音频文件」和单文件 < 4MB；
- 避免「AI 生成 / 来源不明」的动物声，尤其是长臂猿这种旗舰物种；
- 声音的「材料感」比「真实感」更重要；远山猿啼只需要一个方向、一个距离、一个时辰。

如果 R2 决定加一个真实录音，必须：授权清楚、署名在图版注 / 片尾、单文件、可一键关；且不要把它说成「现场录音」。**不要**用 AI 生成的长臂猿叫声冒充真实录音。

## 8. 实现建议

### 8.1 结构

- 一个 `AudioContext`；一个 `master`；一个 `limiter`；`wet` / `dry` 两条滤波支路；一个 `analyser` 给 lab 用（正式页可不接）。
- 共享噪源：4s 棕噪 + 4s 白噪，`ctx.sampleRate` 生成一次；所有颗粒从同一个 buffer 取随机 offset。
- `Layer` 工厂：`{source, filter, gain, pan, lfo}`；`start()` 永远 0 增益；`stop()` 80ms ramp。
- `Act` 控制器：只建当前 + 下一幕的层；`setAct` 时交叉；上一幕 2s 后停。
- 一次性事件池：8 个 voice，预建 gain / filter，播放时只改参数，不 new 节点。
- 每帧不做 `new`；参数更新 10–20Hz 就够；`setTargetAtTime` 不要每帧重复排。

### 8.2 预算

| 项 | 上限 |
|---|---|
| 同时发声源 | 16 |
| BiquadFilter | 8 |
| Delay | 4 |
| Convolver | 0 |
| 每帧分配 | 0 |
| 音频 CPU（中端手机） | < 3% |
| 峰值 | ≤ −6dBFS |

### 8.3 与 M0 / ACT-INTERFACE 的接口

- `00`：`Ambience` 继续管；`Sound.setAct('00')` 时把新引擎 master 降到 0，并让 `Ambience.enable()` 保持现有行为。
- `01` 起：新引擎接管；`Ambience` 不再 `update()`，但保留开关状态，05 结束时可以再用它做收尾。
- 幕隐藏：`Sound.setAct(null)` 或 `Sound.pause()`；不要停整个 context。
- `state.reduced`：LFO 深度 × 0.5，颗粒密度 × 0.5，产卵云时长 × 0.5；不自动开声音。
