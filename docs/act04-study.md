## 0. 一句话

摊开的更路簿占左 2/3。一条 12 段的针路从水里起笔，划过的段过了水线才变成星金；第 12 段到岸，得「更」。停下来，线会干掉，被水擦回起笔处。

## 2. 做法

### 2.1 版式

- **≥820px（1280 / 1440）**：海图从 `x=4.8%w / y=7.2%h` 起，宽 `53.5%w`、高 `85.5%h`；右列从 `65.5%w` 起、宽 `30%w`；图版宽 `42%w`（clamp 300–620），右侧偏下、压在纸上，并压进海图右下角约 65px；字与线都可以压过图版。
- **<820px（390）**：copy 在顶部（kicker / 标题 / 两行正文），海图 `y=140..H−76`；图版 42% 宽贴海图右上；8px 标签、64px 的字块；hint / 读数在水线附近（恒为湿侧，骨白）。
- 所有标题、正文、岛名、图版编号、竖排原文都是 **act 画的真文字**；图版不给任何字。

### 2.2 12 段针路

- 24 方位是 15° 一格；方向表只用 `-45 / -60 / -75` 三档，12 段**等长**（一更），从水里起笔、终点落在猫峙的港点。
- 未划：0.8px、ink 0.38；已划：1.2px 星金（干）/ bone 0.9（湿）；段界是 0.6px 十字 + 1.8px 金点；第 12 段完成时终点画一枚四向星。只在海图下沿留一条无数字的「更」尺。
- `pathAt(u)` + `nearest(x,y)`（逐段投影）负责进度；交互只改 `S.prog`，几何在 resize 时一次算好。

### 2.3 交互

- **起笔**：pointer down 落在针路上、靠起点（u < 0.2），或在干燥后重新起笔；按在线的中后段只提示「从水里起笔。」。
- **划**：`nearest` 投影大于当前 target 才推进；`S.prog` 以 1.9/s 追 target，稍有“线被手指拉住”的滞后。
- **停**：抬指 → settle 0.7s → dry；在线上按住不动 1.6s 也会 dry；离线 0.5s 立即 dry。干燥 2.4s：金去饱和成墨，再从笔头往起点退回；可以重新起笔。
- **微文案**（全部来自 copy deck a04）：起笔「从水里起笔。」/ 过水线「线干了，变成星金。」/ 到 93%「猫峙。」/ 完成「第十二更。」。
- **第 12 段**：`complete()` 调一次 `s.onCollect('更')`（`S.granted` 保护，钩子不存在时不报错）。字块用 12 条横向切片“洇”出来，不画第二条水线；`到岸 / THE 12TH LEG` 是页面真文字。
- **reduced-motion**：起点不呼吸、图版不折射、字直接出现；内容完整，不跑持续动画。

### 2.4 干 / 湿

- 每帧两遍：`ctx.clipAbove(s.lineY)` 画墨版；`ctx.clipBelow(s.lineY)` 画骨白版（湿版整体 `blur(0.35px)`，图版另做切片折射）。没有自己的水线。
- 水线切过针路、罗盘、门、岛、字；同一条线在水上是星金，在水下是骨白——这是本幕的核心读法。
- 图版：干侧 `multiply` 0.92（对齐 `docs/plate-log.md` 的 CSS：`filter:grayscale; mix-blend-mode:multiply`）；湿侧 4 条横切片、±1.4px 的 sin 偏移、alpha 0.27 + 5% 骨白，像水下残影。框、编号、角标、竖排图版原文都由 act 画；海图边框画在图版之后，所以页面的线真的压过图版。
- 字块落在折痕上时，书口折线会让开一条缝（`drawPaper` 里判断 `S.word`）。

### 2.5 图版

- 42% 屏宽（30–50% 区间内），**不铺满**；裁 `(300, 170, 900, 600)`：留下空纸 + 环礁 + 虚线，去掉自带的罗盘（避免和画出来的 24 格罗盘重复）。
- 相对路径 `../../assets/plates/treated/04-route.webp`：`labs/act04/` 与 `js/acts/` 都是 hainan 下两级，Lead 移动后不用改；加载失败时画程序化的空海图兜底，版面仍成立。
- 编号 `图版 04 / PLATE 04` 由 act 画，右对齐贴图版右上角；竖排原文 `用乾巽，使到十二更。` 放在图版左侧的页边（桌面）。

### 2.6 字与色

- 字体：Noto Serif SC（标题 500、岛名、更）/ Noto Sans SC（kicker、hint、status、图版 label）/ Consolas（编号、读数、英文 micro）。
- 字距 helper 在 resize 时预算每个字的 `pos`，每帧只 `fillText`；8px 中文、6.1–6.6px 英文 micro、7.6px 读数。1280 标题 57.6px（clamp 36–62），正文 13.4px（clamp 10.5–14.5）。
- 只用 tokens：ink `#111310`、bone `#F2ECDF`、sea `#03100F`、teal `#16332F`、星金 `#C9A96A`；无珊瑚朱、无新渐变。线：主 1.05–1.2 / 细 0.5–0.8 / 点；填充 2.8–4%。

### 2.7 画面里的东西

- 罗盘：24 格、8 主向、一根不转的针、北东南西四字（r > 44 时）。
- 12 段针路 + 12 个更界标 + 起始呼吸点 / 笔头环。
- 猫峙（终点港点 + 旧名 CAT ISLAND）、峙、门（缺口的两段弧）。
- 流水簿（一列细横线，不写数字）、浅滩（成簇开圈）、星点（桌面 11 + 3 颗固定）、纸纹 / 折痕 / 书口 / 角标 / 更尺。

## 3. 可复用

1. `pathAt()` + `nearest()` + 等长 12 段，适合任何“沿一条线划”的幕；换成潮痕、岸线也只是换 `DIRS` 和端点。
2. 图版处理：干 `multiply`、湿切片 ghost、框/编号/原文都是页面画的，且相对路径在 `labs/actNN/` 与 `js/acts/` 通用。04 的图版裁剪避开了自带的罗盘，其它幕可以照做。
3. 字距 `prep/put`：resize 预计算字位，运行时只画；8px + 6.6px 的中英双行标签可直接搬。
4. 干湿两遍 + 动态 clip 的写法、以及“线自己会变色”的读法，可作为 05 归潮之前的收束。
5. 小动作语言：起点呼吸、笔头环、段界金点、完成四向星——都不抢水线，面积很小。

## 4. 性能

- 单 canvas，无离屏；每帧两遍。`?perf=1` 实测 act 自身绘制耗时（不含 harness）：
  - **1280×800：60fps / 4.0ms**
  - **390×844 DPR2：2.1ms**（iframe 截屏环境里 rAF 被节流，FPS 读数不可信，以 ms 为准）
- 每帧成本：约 150 个纸点 ×2、图版 1 次（干）/ 4 次（湿）、约 30 条 stroke、约 150 个 glyph；干侧无滤镜，湿侧只有一次 0.35px blur。图版 280KB 本地缓存；无外部字体 / CDN。
- 若 R1 还要再省：把纸纹 / 图版 / 静态标签缓存成 ink/bone 两张离屏；目前 4ms 的余量够，先不加复杂度。

## 5. R1 注意

- **收集**：`s.onCollect('更')` 只在第 12 段完成时调一次；钩子缺失不报错。Lead 的存储层拿到后按幕顺序存；字条目的 `act: '04'`。
- **调试钩子**（不传就不影响生产）：
  - `?trace=0.72` 固定进度（本页截图用的就是这个）；
  - `?perf=1` 左上角显示 FPS / 绘制 ms；
  - `?auto=0.7` 合成一次拖动（沿针路划到 70% 后松开，用来看干燥段；属于 QA 工具，可删）。
- **键盘**：act 没有抢全局 keydown，避免和 shell 的滚动 / 水线通道冲突。建议 shell 在 04 幕提供 Enter/Space 或一个明写的“划到岸”可访问路径；act 的 `advance` 目前没有对外暴露，Lead 需要的话我可以补一个 `A.demoTrace(u)`。
- **单文件**：构建时把 `assets/plates/treated/04-route.webp` 内联（或保留相对路径）。图版缺失会自动退回程序化图版，版面仍成立，但“旧纸 / 环礁”的质感会弱。
- **水线**：只认 `s.lineY`；shell 里不要给 04 再加第二条线或淡入转场。
- **例外说明**：04 是允许用 AI 图版的幕，因此“无外部图片”在这里指无 CDN / 无远程字体；图版本地随包。
- **极端宽度**：<820 用手机版（按 390 优化）；600–819 的平板没有单独打磨。
- **文案**：全部来自 copy-deck a04；额外用了 deck 里可选的图版原文 `用乾巽，使到十二更。` 和微文案 `到岸` / `第十二更。`；没有新增数字（只有 12 段、12 更、60 里）。

## 7. 已知取舍

- **图版在 1280 p=0.55 被水线切掉大半**：这是刻意的“水下残影”，把干侧留给海图与 copy；p=0.9 时整张图版是干的（见 done 截图）。移动版图版在水线上，p=0.55 时整张是干的。
- **右上角空纸**：完成前留白，完成后由「更」的字块（78px 框 / 移动 64px）填上；桌面另补三颗星点，不让它太空。
- **图的编号**：用 `图版 04` 对应幕号 / 文件名，不用 plate-log 的“3/3”序数，避免和幕号混淆。
- **hint 在底部**：移动端 hint / 读数常在水线附近（恒湿），是主动选择——这样干侧留给 copy 与图版；如果 shell 底部有固定 UI，按 shell 的 safe-area 再上移 8–12px。
