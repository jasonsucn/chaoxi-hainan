## 0. 读法

每一幕是一张卡：`kicker` / `title` / `body` / `plates` / `interaction` / `collectible`。

字段前的 `a01.kicker` 这样的字符串是交接 key，场景 agent 直接取用；`body1`、`body2` 是两行正文，换行是语义，不要为了排版重断。

三条硬规则：

1. **只写水做的事。** 露出、擦掉、拖、按住、划、推回。不写「淡入」「渐显」「浮现」。
2. **每句至少一个具体名词。** 石头、气孔、沙、贝壳、线、盐、卵、针路、纸、月。
3. **不确定的数字不写。** 有来源的数字放 §6；正文只保留「一更六十里」「六小时十三分」这类可考的。

**禁用（供 QA 搜词）**：椰风海韵、东方夏威夷、必打卡、治愈、宝藏、绝美、人间仙境、出片、氛围感；感叹号；「让我们一起」；「你有多久没有」；任何编造的统计。

**英文**：只做图版 micro-label、幕名索引、数据读数。不写英文正文。

## 1. 五个字

每一幕只有一个字是完整的；其余都是半成字，会被水擦掉。五个字按顺序进潮汐笺：`火 · 拾 · 卵 · 更 · 汐`。少一个就留一个空位，不补假字。

| 幕 | 字 | 怎么得到 | 团队备注（不写进正文） |
|---|---|---|---|
| 01 | 火 | 按住玄武岩 2–4 秒，热从气孔里渗出来 | 火山留在石头里的白天 |
| 02 | 拾 | 拖水线，捡起唯一一个完整的字 | 赶海的动作本身 |
| 03 | 卵 | 光停住两秒，珊瑚打开，卵囊升起 | 一场很慢的雪 |
| 04 | 更 | 沿针路划到第十二更 | 航程单位，一更六十里 |
| 05 | 汐 | 把海推回去，最后留在纸上 | 夜里的潮 |

```json
  { "act": "02", "char": "拾", "t": "..." }
] }
```

### 6.2 不确定 / 故意不写

- **黑沙滩的具体岸段**：正文只写「黑沙」这个材料，不点海湾名。「海南最美黑沙滩」这类说法没有可靠来源。
- **「用光唤醒珊瑚」**：这是交互隐喻，不是科学结论。真实产卵由月相、水温等触发；图版注里已把真实时间写清楚。
- **「卵」是简写**：多数造礁珊瑚释放的是精卵囊（gamete bundle），不是单个卵；正文用「卵」，图版标「卵囊」，不把生物学名词塞进诗里。
- **西岛珊瑚石屋的数量 / 年代**：媒体口径（500 多年村落、100 多幢），未核学术来源；正文不写数字。
- **「一更」的长度**：60 里（官方非遗页）与「一昼夜航程的十分之一」（光明日报）两说；正文用 60 里，不在页边写另一说。
- **大潮日期**：不写成「潮汐预报」；卡片只说「下一次大潮」，不承诺「最大潮差」。
- **汐**：通常释为夜间的海潮（与「潮」相对）；如需更严谨，贴图时可写「晚潮」。正文保留「夜里的潮」这个短注。
