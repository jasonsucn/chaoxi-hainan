# 美术方向 / ART DIRECTION

## 0. 一条规矩

**所有东西只能被水「露出」或「擦掉」，不许淡入淡出。**

水线以上：盐白、玄武墨、干。水线以下：南海青、骨白、湿、折射。
这条规矩高于任何单幕的视觉想法。每一幕都必须在水线两侧成立。

## 1. Tokens

```css
--ink:   #111310;   /* 玄武墨 */
--bone:  #F2ECDF;   /* 骨白 / 盐白 */
--sea:   #03100F;   /* 最深的海 */
--teal:  #16332F;   /* 南海青 */
--coral: #D8503A;   /* 珊瑚朱：只给潮位尺 / 极少数强调 */
```

每幕只加 **一个** 材料强调色，不与珊瑚朱抢：

| 幕 | 材料 | 强调色 | 用法 |
|---|---|---|---|
| 01 玄武 | 玄武岩 / 火山灰 / 珊瑚石灰墙 | `#8C4A38` 锈红；`#E8E2D4` 石灰白 | 石头的热、灰、墙的孔 |
| 02 潮间带 | 湿沙 / 贝壳 / 黎锦线 / 盐晶 | `#2B4C7E` 黎锦靛（一根线，面积 < 2%） | 只在一根线/一个标签上 |
| 03 珊瑚 | 珊瑚 / 产卵 | `#E2452F` 活珊瑚；`#7FE3D4` 荧光青（极少） | 粒子/光，面积 < 5% |
| 04 航线 | 更路簿 / 星图 | `#C9A96A` 星金 | 航线、星点、图版标签 |
| 05 归潮 | 月 / 潮汐笺 | `#C8D2D4` 月银 | 月、纸、收束 |

**禁止**：彩虹渐变、金色光效、玻璃拟态、紫蓝科技感、AI 光泽、纯黑纯白大面积。

## 2. 线 / 填充

- 主轮廓线：`1.0–1.2px`（CSS px）；地图是 `1.05`，椰树是 `1.0`，新幕不要超过 `1.2`。
- 细线：`0.6–0.8px`，只用于叶脉、刻度、边注。
- 填充：`3–4%` 不透明度；永远不要实心色块（除非是 < 4px 的点/字）。
- 端点：`round`；连接：`round`；不要虚线（图版标签下划线除外）。
- 每幕最多 **三种线重**：主轮廓 / 细线 / 点。

## 3. 字体

- 标题：`Noto Serif SC`，500/600；大字距；可竖排。
- 数据 / 边注：`Noto Sans SC` 300/400，字号 7–10px，字距 0.18–0.3em。
- 数字 / 坐标：`Consolas` 或等宽，8–10px。
- 单文件交付时做子集内嵌；开发期用系统字体。
- 中文为主；英文只做图版注记（小号、大写、宽字距）。

## 4. 动效

- 只有一种缓动家族：**潮汐缓动**（长尾减速，`cubic-bezier(.2,.72,.18,1)`）。
- 没有弹跳、没有回弹过冲、没有旋转 360° 的图标。
- 一切运动要有物理理由：水、风、热、光、重力。
- 滚动驱动优先于时间驱动；用户控制节奏。
- `prefers-reduced-motion`：静态图鉴版，内容完整，不跑持续动画。

## 5. 每幕的材质与构图

### 01 玄武
- 火山岩的孔、黑沙的颗粒、珊瑚石灰墙的孔洞。
- 构图：一块石头占据 1/3，水线切过它；热从石头内部渗出来（珊瑚色，只在按住时）。
- 交互：按住 → 升温（慢，2–4 秒）；松手 → 变凉（更慢）。不要进度条。

### 02 潮间带
- 湿沙的镜面、贝壳的虹彩（极淡）、字被水擦掉。
- 构图：一条退潮后的岸线；散落 3–5 件证物（黎锦线、盐晶、落叶、贝壳、字）。
- 交互：拖水线；点击/长按捡起一个词；词进入潮汐笺。
- 这是全篇的核心幕；水线的拖拽手感必须和 M0 一致。

### 03 珊瑚
- 深青、珊瑚虫的触手、产卵的粒子雪、pointer 光。
- 构图：暗场，只有被光扫到的珊瑚亮；水线以上是干的骨白/墨，以下才发光。
- 交互：移动光；停在一处 2 秒 → 珊瑚打开/产卵。不要点击爆炸。

### 04 航线
- 旧纸、手绘航线、旧岛名、星点。
- 构图：一张摊开的更路簿/海图，占 2/3；航线是细线，岛名是 8px 边注。
- 交互：沿着航线划一笔；划过的部分留下星金细线。不要画满。

### 05 归潮
- 月银、深靛、潮水回来、纸。
- 构图：水线升回来，把前面的证物一件件收走；最后一张潮汐笺。
- 交互：收下/保存；可「再等一次潮」回到开头。

## 6. AI 图版规范

只允许 3 张：01 玄武、03 珊瑚、04 航线。

- 作为**图鉴插页**，不是全屏背景；宽度 30–50%，带图版编号/标签/细线框。
- 处理：双色调到该幕 palette；2–3px 网点；颗粒；轻微套准偏移；可加 1px 线框。
- 禁止：AI 光泽、塑料质感、可读的乱码文字、人脸、品牌 logo。
- 图版必须能被页面上的真实文字/线覆盖；不要在图里烧字。
- 每张图版配 4–6 个标签（中文 + 英文 micro-label），由 copy deck 提供。

## 7. 性能预算

- 目标：390×844 中端机 60fps；最低 45fps；桌面 60fps。
- DPR 封顶 2（粒子层 1.5）；单幕 canvas 不超过 2 个；离屏缓存静态纹理。
- 每幕的持续动画不超过 2 个系统（例如：水线 + 粒子）；其他靠滚动/交互触发。
- 隐藏时暂停 rAF / 音频；页面不可见时全部暂停。
- 首屏 < 2.5MB；单文件 < 4MB（含字体子集）。

## 8. Review checklist（每个 act 必过）

- [ ] 390 / 1280 / 1440 三种宽度；干/湿 × 3 个潮位。
- [ ] 水线和 `lineY` 完全对齐；没有一条自己的“假水线”。
- [ ] 只用 tokens + 该幕一个强调色；没有新字体/新渐变。
- [ ] 主轮廓 1.0–1.2px；填充 3–4%；没有实心大色块。
- [ ] 动效只有潮汐缓动；没有弹跳/旋转。
- [ ] 交互有物理理由；键盘/触摸可用；有 reduced-motion 静态版。
- [ ] 60fps（或 45fps 以上）；无 console error；无外部图片。
- [ ] 文案来自 copy deck；事实有来源；没有旅游套话。
