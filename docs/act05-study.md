## 2. 做法

### 2.1 版式

- **桌面（≥820）**：纸在 `x = 0.665W` 居中，`h = clamp(0.56H, 350, 540)`、`w = 0.644h`（1280×800 → 288×448）；月亮在 `(0.70W, 0.108H)`，r `min(0.048W, 0.075H)`；页边注在 `0.902W`，从 `0.40H` 往下竖排（copy-deck §5 第 5 条）；四个字列 = 纸的前四个字位。
- **移动（<820）**：纸宽 `min(0.625W, 268)`，高度按 0.644 比例，卡顶约 `0.375H`，底部给 shell 的 readout / hint / `found` 留 ≥104px；月亮降到 `(0.715W, 0.135H)`，朔望在月下；页边注在移动端省略（右侧留给 shell 的 gauge）。
- 字列 `x = 纸x + 0.30w`；标签右对齐在字列左侧（01 玄武 / BASALT…）；表头「拾得 / THE WORDS FOUND」在第一个字上方。
- 所有位置随 `resize` 重算；字位、页边注、纸纹都在 resize 时种一次，不在每帧分配。

### 2.2 四个字 / 五个字位

- 纸的五个竖排字位固定在 `0.245 / 0.345 / 0.445 / 0.545 / 0.645`（卡高比例）。场景里的四个字就画在前四个字位；第五位（汐）从一开始就是一条 8px 空横线——先铺好纸的骨架，最后纸才落下来。
- **收字时机**按 shell 的水线算：`takeAt = 1 - ((slotY/H) - 0.078) / 0.822`（`journey.js` 的 lineStart/lineEnd 近似），再 clamp 到 `0.32–0.82`。这样在 shell 里“水线刚好到字”时，字开始被擦；桌面约 p=0.66 / 0.59 / 0.52 / 0.46（火→更，从下往上）。窄屏的卡更低，`takeAt` 更早（≈0.49 / 0.44 / 0.38 / 0.33），所以 390 的 p=0.55 四个字位已经收完；空字位旁的幕名仍留在页边，直到纸把它们盖住。
- 擦除：字 / 标签 / 幕号一起被 `wipe` 的横向裁切从下往上吃掉；前沿留 3 条 0.55px 横丝 + 2 个 1px 点（墨 / 骨白随干湿），没有粒子爆炸。擦完留下 8px 空字位 + 幕名（`01 玄武` … `04 航线`），像收据上的一行。
- 每个字后面有一件很小的证物线（0.8px，填 3%）：玄武岩气孔 / 贝壳扇 / 珊瑚枝 / 四向罗盘，跟着字一起被收走。它们是 05 对 01–04 的唯一“证物”指涉，不抢字。

### 2.3 潮汐笺（视觉层）

- **纸是唯一“干”的东西**：画在两次 clip 之外。`rgba(bone, 0.952)` 纸面 + 1.05px 墨框 + 5px 内细线 + 四角 0.6px 裁切角标 + 2–3.4% 墨纸纹（64 点，resize 时播种）。无阴影、无渐变、无圆角。
- **出现 = 晾干**：`rev` 由 05 local p `0.84–0.895` 直接驱动（scroll-driven，不做 fade）；clip 的上沿是卡顶，下沿是 `card.y + h*rev` 的 `ctx.waveAt()` 波动。纸上一道墨边、纸下一道骨白湿边 + 7 个泡沫点；一条「只剩这一张是干的。」贴在纸的上沿。到 `rev≈1` 前沿消失。
- **内容**（copy-deck §4）：`潮汐笺 / TIDE CARD`、珊瑚朱小印「潮」、五个竖排字（字距 0.3em）、`拾得 / WORDS`、右下三行 `日期 DATE / 月相 MOON / 潮时 TIDE`、`收好这一页。海会再来。`、`潮汐书 · 海南 / 页内潮程 6h13m / XR LAB 2026`。空位是一条 8px 横线（用一张只有「火」的数据核过；不会补假字）。
- **汐**：`rev` 到 0.70 时（≈ local 0.878）把 `汐` 写进第五位（从上往下 0.016 p 的墨），同一帧调一次 `ctx.onCollect('汐')`。纸在 p=0.90 时是满的。
- **按住收好**：卡完整后，在纸上按住 1.15s：印里的珊瑚墨从下往上涨；满 → 印变实、字变骨白、提示从 `按住 · 收好 / HOLD TO KEEP` 变成 `收好。/ KEPT`。松手会退（慢一点），不弹窗、不连击。
- 纸上的字位、印章、日期读数都能被页面上的真实线/字覆盖；卡不接收外部图片。

### 2.4 月 / 朔望 / 页边注

- 月是 05 的材料色 `#C8D2D4`：纸上是一枚灰银的月亮（0.66），水里更亮（0.88）；外圈 1.05px，明暗界线是向左鼓的椭圆，三个 0.6px 小坑。月不遮字。
- 「朔望 / SYZYGY」：一个小空圆 + 一个小实圆（0.8px），右侧/月下 8px 标注；在 `p` 上是固定的，不跑动画。
- 页边注只用 copy-deck §5 第 5 条：`盐是海退走以后，留在石头上的标点。` 竖排 7.6px、一条 0.6px 侧线；如果 Lead 的 shell 要自己放这条，删 `drawNote()` 即可。
- 水面：月亮反射（仅当水在月下）6 条 0.6px 横线；手指按在水里出现 3 圈 0.55px 月银水花（最多 5 组，1.15s 内消失）。没有第二条水线。

### 2.5 干 / 湿

- 每帧两遍：`ctx.clipAbove(s.lineY)` 画墨；`ctx.clipBelow(s.lineY)` 画骨白 + `blur(0.35px)`（与模板/04 一致）。水线只有一个。
- 例外：**纸**。潮汐笺 / 章节文案之外的“干”对象；纸上的文字、框、印是墨，纸面是骨白。这是 copy-deck「纸的矩形，1px 线框」的读法，也是 05 的收束：纸不能被水擦掉。它占了屏面约 7–17% 的浅色面积（桌面 288×448 / 移动 244×378），Review 时可讨论是否收小；内部仍是 3–4% 的纸纹、1px 线，没有实心装饰块。
- 色彩：只用 ink / bone / sea / moon；珊瑚朱只给纸印「潮」（≤ 24px）；不画潮位尺（shell 已有 gauge）。行宽 1.05 / 1.2；细线 0.55–0.8；填充 3–4%。字体 Noto Serif SC（标题、字、收束）/ Noto Sans SC（8px 标签）/ Consolas（读数、英文 micro）。

### 2.6 交互

- **按住收好**（结尾）：pointer down 在纸内且 `rev > 0.992`；1.15s 满；`A.seal()` 也提供程序化收好（给 shell 的键盘/按钮路径）。
- **推水**：水线以下、纸外，按下/拖动 → 月银水花（3 圈 + 2 点）；没有状态改变，纯水体反馈；不连击、不爆炸。
- **指针来源**：`shell` 的 `s.pointer` 只有 `x / y / tx / ty`，**没有 `down`**（`journey.js`）。本 act 在 mount 时自己在 `ctx.root` 上加 `pointerdown`、在 `window` 上加 `pointermove/up/cancel`，unmount 时移除；`s.pointer` 只在未绑定事件时兜底。`act02` 也是这样做的。这样 shell 里按住卡 / 推水都能用。
- **reduced-motion**：水花关闭、月亮反射冻结、晾干仍由 p 驱动（不跑持续动画），内容完整；按住仍可用（用户自己控制）。
- **键盘**：act 没有抢 keydown（避免与 shell 的 Arrow/PageDown 冲突）。建议 shell 在 05 提供 Enter/Space → `ACTS.list['05'].seal()`；否则“收好”只有指针路径。
- **A11y**：hold 没有进度条；印的墨面就是进度（物理：按下印章），也让“收好”不依赖精确点击。

## 3. 可复用

1. **字位 = 卡位**：先把潮汐笺的五个字位算好，场景里的四个字直接落在前四个字位；卡出现时自然接上。任何“最后落成一张纸”的幕都能借用。
2. **倒置幕的收字时机**：`takeAt = 1 - ((slotY/H) - lineStart/H) / ((lineEnd-lineStart)/H)`，让 act 的擦除和 shell 的水线在**真实 shell**里对齐；lab 若没反转只是预览镜像，不影响。
3. **晾干式出现**：clip 的上沿固定、下沿用 `ctx.waveAt` 波动；纸边一墨一白、泡沫 7 点；没有 fade、没有新渐变。
4. **一张纸 = 唯一干物**：两次 clip 之外画纸；纸上的内容全用墨 / 珊瑚印；干湿都由“纸”承担，场景还是两遍。
5. **指向“证物”的极小线图**：0.8px 的石头/贝壳/珊瑚/罗盘，跟着字一起被裁掉；不靠图片也能指涉 01–04。
6. **印章按住**：印里的墨面从下往上涨，替代进度条；可以是任何“按住确认”的收束。
7. **文字排版 helper**：`prep/put` 的 tracking（`putTracked`）和 8px 中英双行标签、等宽读数，可直接搬。

## 4. 性能

- 单 canvas，无离屏；每帧两遍 clip（干/湿）+ 一次 `blur(0.35px)`（仅湿）。
- 实测（临时计数器，已删；1280×800、DPR1、p=0.90、整张卡）：**约 2.1ms / frame**；p=0.55 的字列更少。按 60fps 预算（16.7ms）有大量余量；390×844 DPR2 的绘制量更小（卡 244×378），仍在 60fps 目标内。
- 每帧绘制：卡 1 次纸填充 + ~40 次 `fillText` + 64 个纸纹点 + ~12 条线；场景 4 个字 + 4 个线图 + 8 个标签 + 月/朔望/页边注 + 6 条反射；水花最多 5×4 条弧。没有逐帧 `measureText`（只有卡标题 tracking 的 3 个字）。
- 无外部图片 / 字体 / CDN；没有持续粒子系统；隐藏时 shell 负责暂停 rAF。

## 5. R2 钩子（潮汐笺）

**数据**

```js
ACTS.list['05'].setCardData({
  date: '2026.10.23',                 // yyyy.mm.dd
  moon: '盈凸',                        // M0 moonInfo.name
  moonEn: 'WAXING GIBBOUS',
  tide: '16:20 → 22:33',              // 进页时刻 + 6h13m（页内潮程）
  words: ['火', '拾', '卵', '更'],      // 只放拾到的；顺序由字固定
  closing: '收好这一页。海会再来。'
});
```

- `getCardData()` → `{ date, moon, moonEn, tide, words, slots, closing }`；`slots` 是 5 个位置的数组，缺字为 `null`（导出时用 8px 横线，不补假字）。
- 字序固定 `火 · 拾 · 卵 · 更 · 汐`；`汐` 在卡晾到 0.70 时自动加入，并在同一帧调一次 `ctx.onCollect('汐')`（或 `s.onCollect`；都没有就静默）。
- 默认值：进页本地日期；M0 `moonInfo` 公式的副本（仅作默认，R2 应传 shell 的真实值）；`mount` 时刻 + 6h13m。R2 应在 shell 的 `S.started` / `clockText` / `moonInfo` 上取值覆盖。
- 状态：`A.progress`（0..1）、`A.cardVisible`、`A.collected`、`A.sealed`；`A.getCardState()` 返回 `{ rev, visible, granted, sealed, hold, cardWet }`。
- 声音：`A.onCardShown = fn`（rev 第一次过 0.5，卡露出）、`A.onSealed = fn`（收好）。建议 `tidebook.card` 在这里播；R2 的纸滑入 220ms 是时间动画，卡本身是 scroll-driven 的，音效跟 `onCardShown` 即可。
- 程序化收好：`ACTS.list['05'].seal()`。

**几何**（导出用）

`A.cardSpec()` 返回：`ratio 0.644`；`slotFractions [0.245,0.345,0.445,0.545,0.645]`；`wordX 0.30`；`labelFractions { title:0.101, rule:0.16, date:0.792, moon:0.843, tide:0.896, closing:0.944, footer:0.978 }`；`frame { lineWidth:1.05, inset:5, lineWidth2:0.65 }`；`rect`（当前屏上位置）。R2 可按同一组比例在 2× 画布上重画，视觉与屏上一致。

**版式**：五字竖排、字距 0.3em；空字位 8px 横线；日期 / 月相 / 潮时右下等宽小字；卡面文案见 copy-deck §4。纸无阴影、渐变、圆角；珊瑚只给印「潮」。
