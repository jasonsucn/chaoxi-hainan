# 声音 lab / SOUND LAB

`docs/sound-map.md` 的可听原型。不是正式页，不进单文件构建，不碰 `js/audio.js`。

## 打开

Lead 的静态服务已起在 `4174`（root = `hainan/`）：

```
http://127.0.0.1:4174/labs/sound/
```

也可以直接双击 `index.html`（`file://`）——没有外部资源，全部程序化合成。

## 它验证什么

- **水线驱动**：潮位滑杆同时改 `wet` / `dry` 两条滤波支路的增益与截止频率；不是时间淡入淡出。
- **5 幕 bed**：00–05 各 2–4 层，只有当前幕的 bus 打开；切幕用 0.12s 的 `setTargetAtTime` 交叉。
- **移动端解锁**：第一次 pointer / key / touch 才创建 `AudioContext`；右下状态会显示 `locked` / `unlocked`。
- **静音记忆**：`localStorage['tidebook.sound.lab.muted']`；刷新后保持。
- **一次性事件**：拾字（纸 + D4）、按住升温（滤波开合）、停光 2s（产卵颗粒云）、划一笔（铅笔噪声）、收下（盖章 + 80ms 干拍）。
- **看得到的声音**：`AnalyserNode` 的时域波形画在水线上。

## 怎么玩

1. 点任意处或「声音」按钮解锁；默认 `OFF`。
2. 拖「潮位 TIDE」：0 = 满潮，1 = 见底；幕会跟着区间自动切换，也可以点幕按钮。
3. 点「拾字」「停光 2s」「划一笔」「收下」听一次性事件；「按住升温」要按住不放。
4. 刷新页面，看声音开关是否记住。

## 不是什么

- 不是 M0 的声音系统；M0 仍由 `js/audio.js` 负责，00 的 bed 在这里只是简化模拟。
- 不是最终混音；电平、滤波、颗粒密度都还要在正式页里按 `docs/sound-map.md` 调。
- 不是真实录音：远山猿啼、鼓虾、产卵、纸、铅笔全是合成的「印象」。
- 不证明真机性能；音频 CPU 和 60fps 要等 R1/R2 在真机上测。

## 已知简化

- 石头 tick、沙粒、鼓虾用的是 LFO 纹理，不是真正的颗粒调度器；正式实现按 `docs/sound-map.md` §3 的包络做。
- 「停光 2s」是一个按钮，不是真实的光标停留检测。
- 键盘可点按钮，但「按住升温」只绑了 pointer 事件；正式页要补键盘的 press-and-hold。
- 没有接 `prefers-reduced-motion` 的 LFO 减半；正式实现要补。
